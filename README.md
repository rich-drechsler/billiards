## A 3D Billiard Aiming Demo

What you'll find in this repository is a 3D billiard aiming demo that should run
in any modern browser. It depends on the Three.js JavaScript library, but it's
otherwise a self-contained, single-file application, so point your browser at

    https://rich-drechsler.github.io/billiards/aiming.html

and it should start running. What you get is a boring look at several strangely
colored billiard balls sitting on a flat green surface. Its only purpose is to let
you visualize aspects of aiming in pool that might be difficult or impossible to
replicate on a real pool table with opaque balls.

Google's Gemini 3.5 Flash and I built this version in a few weeks using an old
Yoix script (that I believe I wrote in 2012) as a reference model. I've included
that old script as

    legacy/aiming.yx

in this repository, just in case you're curious to see what we started with.
